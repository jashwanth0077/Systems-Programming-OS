# Systems Programming | Operating Systems

**Academic Project — Spring 2024**  
Instructor: Mythili Vutukuru

Course: **Systems Programming / Operating Systems**

---

## 📌 Overview
This project was developed as part of the **Operating Systems** course.  
It focuses on extending the Linux kernel with **new system functionalities**, memory optimizations, and synchronization mechanisms for concurrent programming.

---

## 🔑 Key Features
- **Custom System Calls & Scheduler**
  - Designed and integrated new system calls.
  - Implemented a **Weighted Round-Robin Scheduler** for fair and efficient process scheduling.

- **Memory Management**
  - Implemented **`mmap`** for dynamic memory allocation.
  - Developed a **Copy-on-Write Fork** mechanism to optimize memory usage and improve process management efficiency.

- **Concurrency & Synchronization**
  - Implemented **Reader-Writer synchronization** using **pthreads**.
  - Used **locks** and **conditional variables** to manage concurrent access to shared resources safely.
